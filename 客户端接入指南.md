# 客户端接入指南（引擎无关）

> 适用于所有游戏引擎：Unity、Cocos Creator、Unreal、自研引擎等。
> 你只需要能发 HTTP 请求即可接入。

---

## 一、接入三步走

```
Step 1: 在管理后台注册游戏 → 获取 game_id
Step 2: 代码里发一个 HTTP POST 请求
Step 3: 完
```

---

## 二、上报接口

### 接口地址
```
POST https://your-attribution-server.com/api/v1/report
Content-Type: application/json
X-Attribution-Api-Key: 你的客户端上报API密钥
```

### 请求体完整格式

```json
{
  // === 必填字段 ===
  "game_id":  "你的游戏ID（管理后台注册后获得）",
  "platform": "apk",
  "event":    "activate",
  "device": {
    "oaid": "1fe9a970-efbb-29e0-0bdd-f5dbbf751ab5"
  },
  "ts": 1716900000000,

  // === 可选：应用信息 ===
  "app": {
    "version": "1.2.3",
    "channel": "huawei",
    "build":   "20250101"
  },

  // === 可选：用户信息 ===
  "user": {
    "user_id":  "uid_12345",
    "role_id":  "role_001",
    "role_name": "玩家昵称",
    "server_id": "s1",
    "level":     10
  },

  // === 可选：事件参数（完全自定义） ===
  "event_params": {
    // 付费事件
    "revenue":      6.00,
    "currency":     "CNY",
    "product_id":   "diamond_60",
    "order_id":     "ORDER20250525001",
    "is_first_pay": true,

    // 或者其他任意键值对
    "any_custom_key": "任何你想传的值"
  },

  // === 可选：设备指纹（OAID 获取失败时填写） ===
  "fingerprint": {
    "ip":        "1.2.3.4",
    "user_agent":"Mozilla/5.0...",
    "model":     "HUAWEI P60",
    "screen":    "1080x2340",
    "os_version":"HarmonyOS 5.0"
  }
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `game_id` | string | ✅ | 管理后台注册的游戏唯一标识 |
| `platform` | string | ✅ | `apk` / `hap` / `rpk` |
| `event` | string | ✅ | 事件名称 |
| `device.oaid` | string | ✅ | 设备 OAID，无法获取时传空字符串 |
| `ts` | number | ✅ | 事件发生时间戳（毫秒） |
| `app.version` | string | 否 | App 版本号 |
| `app.channel` | string | 否 | 分发渠道 |
| `user.*` | - | 否 | 游戏内用户信息 |
| `event_params` | object | 否 | 事件参数，任意键值对 |
| `fingerprint` | object | 否 | OAID 无法获取时的备选设备信息 |

---

## 三、在什么时机调用

| 时机 | event 值 | 说明 |
|------|---------|------|
| 游戏**首次启动** | `activate` | 最重要的事件，用于归因匹配 |
| 用户**完成注册** | `register` | 创角/注册 |
| 用户**登录** | `login` | 每次登录（可选） |
| 付费**成功** | `purchase` | 必须带 `event_params.revenue` |
| 次日**留存** | `retain_1d` | 激活后 24-48 小时上报 |
| 第 7 天**留存** | `retain_7d` | 激活后 7-8 天上报 |
| **自定义事件** | 管理后台配置的名称 | 如 `level_complete`、`tutorial_done` |

## 四、各引擎代码示例

### 4.1 Unity (C#)

```csharp
using System.Collections;
using UnityEngine;
using UnityEngine.Networking;

public class AttributionManager : MonoBehaviour
{
    private const string REPORT_URL = "https://your-server.com/api/v1/report";
    private const string GAME_ID = "your_game_id";
    private const string API_KEY = "your-report-api-key";
    
    private string platform = "apk"; // 或 hap, rpk
    private string oaid = "";

    void Start()
    {
        // 异步获取 OAID，然后上报激活
        StartCoroutine(GetOAIDAndReport());
    }

    IEnumerator GetOAIDAndReport()
    {
        // 获取 OAID（各平台有各自的获取方式）
        yield return StartCoroutine(FetchOAID());
        
        // 上报激活
        yield return StartCoroutine(Report("activate"));
    }

    IEnumerator FetchOAID()
    {
#if UNITY_ANDROID && !UNITY_EDITOR
        // APK: 通过 AndroidJavaClass 获取 OAID
        using (var jo = new AndroidJavaObject("com.yourgame.OAIDHelper"))
        {
            oaid = jo.CallStatic<string>("getOAID");
        }
#elif UNITY_HARMONYOS
        // HAP: 通过 HarmonyOS 插件获取
        oaid = HarmonyOSPlugin.GetOAID();
#endif
        yield return null;
    }

    public IEnumerator Report(string eventName, System.Collections.Generic.Dictionary<string, object> eventParams = null)
    {
        var body = new ReportBody
        {
            game_id = GAME_ID,
            platform = platform,
            ts = System.DateTimeOffset.UtcNow.ToUnixTimeMilliseconds(),
            device = new DeviceInfo { oaid = oaid },
            @event = eventName,
            event_params = eventParams
        };

        string json = JsonUtility.ToJson(body);
        using (var www = UnityWebRequest.Post(REPORT_URL, json, "application/json"))
        {
            www.SetRequestHeader("X-Attribution-Api-Key", API_KEY);
            yield return www.SendWebRequest();
            if (www.result == UnityWebRequest.Result.Success)
            {
                Debug.Log($"[归因] {eventName} 上报成功: {www.downloadHandler.text}");
            }
            else
            {
                Debug.LogError($"[归因] {eventName} 上报失败: {www.error}");
            }
        }
    }

    // 付费上报
    public void ReportPurchase(double amount, string productId, string orderId, bool isFirstPay)
    {
        StartCoroutine(Report("purchase", new System.Collections.Generic.Dictionary<string, object>
        {
            { "revenue", amount },
            { "currency", "CNY" },
            { "product_id", productId },
            { "order_id", orderId },
            { "is_first_pay", isFirstPay }
        }));
    }

    [System.Serializable]
    class ReportBody
    {
        public string game_id;
        public string platform;
        public long ts;
        public DeviceInfo device;
        public string @event;
        public System.Collections.Generic.Dictionary<string, object> event_params;
    }

    [System.Serializable]
    class DeviceInfo
    {
        public string oaid;
    }
}
```

### 4.2 Cocos Creator (TypeScript)

```typescript
const REPORT_URL = 'https://your-server.com/api/v1/report';
const GAME_ID = 'your_game_id';
const API_KEY = 'your-report-api-key';

async function reportEvent(eventName: string, eventParams?: Record<string, any>) {
    let oaid = '';
    
    // 获取 OAID
    if (sys.platform === sys.Platform.ANDROID) {
        // APK 通过 jsb.reflection 调用原生
        oaid = jsb.reflection.callStaticMethod(
            'com/yourgame/OAIDHelper', 'getOAID', '()Ljava/lang/String;'
        );
    }
    // RPK: 快游戏中调用 qg.getOAID()
    // @ts-ignore
    if (typeof qg !== 'undefined' && qg.getOAID) {
        // @ts-ignore
        oaid = await new Promise((resolve) => {
            // @ts-ignore
            qg.getOAID({ success: (res) => resolve(res.oaid), fail: () => resolve('') });
        });
    }

    const body = {
        game_id: GAME_ID,
        platform: 'apk',  // 按实际修改
        ts: Date.now(),
        device: { oaid },
        event: eventName,
        event_params: eventParams || {}
    };

    try {
        const xhr = new XMLHttpRequest();
        xhr.open('POST', REPORT_URL, true);
        xhr.setRequestHeader('Content-Type', 'application/json');
        xhr.setRequestHeader('X-Attribution-Api-Key', API_KEY);
        xhr.onload = () => console.log(`[归因] ${eventName}: ${xhr.responseText}`);
        xhr.send(JSON.stringify(body));
    } catch (e) {
        console.error(`[归因] ${eventName} 上报失败:`, e);
    }
}

// 使用
reportEvent('activate');
reportEvent('purchase', { revenue: 6.00, product_id: 'diamond_60' });
```

### 4.3 自研/其他引擎

只要能用任意语言发 HTTP POST 请求即可。伪代码：

```
fn report(gameId, platform, oaid, eventName, params):
    body = {
        game_id: gameId,
        platform: platform,
        ts: now(),

        event_params: params

    httpPost("https://your-server.com/api/v1/report", json(body), headers={"X-Attribution-Api-Key": apiKey})
```

## 五、注意事项

1. **不要阻塞启动流程**：上报是异步的，不能影响游戏启动速度
2. **失败不重试**：客户端不做重试（服务端有去重机制），失败就失败了
3. **OAID 获取失败处理**：传空字符串即可，服务端会自动尝试指纹降级匹配
4. **付费必须先发奖**：先给玩家发放道具，再异步上报归因
5. **不要缓存 OAID**：OAID 可能被用户重置，每次上报时实时获取
